# 产品需求

## 产品
慢慢办 · 老年人生活助手

## 用户原始需求
美化ui界面多点人情味

## 目标
在保留现有功能入口、页面结构与文案的前提下，主要优化视觉表现，让界面更温暖、亲切、有人情味，并维持适老化可读性与易操作性。

## 产品语言
中文（简体）

## Screen Type
Mobile primary, responsive to desktop

## 目标用户
需要学习手机操作、处理日常事务、了解防骗知识和管理健康的老年用户。

## 关键功能
- 首页保留“学用微信、生活小帮手、防骗提醒、健康管理”四个入口
- 保留大字模式并记忆用户选择
- 保留“小慢”助手形象、浮动开关与进入对话入口
- 保留四个分类页的现有条目、说明与未开放提示
- 保留 AI 对话页、文字发送、语音准备中提示与尚未接入说明
- 手机竖屏优先，并在电脑端以有意设计的手机内容区呈现
- 支持键盘焦点与减少动态效果偏好

## 视觉要求
温暖、亲切、有人情味；避免生硬的工具感。延续奶油暖色、柔和绿、杏橙与淡紫的基础气质，增强纸张与居家陪伴感。文字清晰、触控区域宽大、状态反馈明确。

## 参考源码
用户附件中的 index.html、main.js、style.css、icons.js、character.js 是功能、结构、文案和“小慢”形象的可信来源；实现需适配平台现有网页工程结构。


## 本次最小版本已落地
- 以“家中手写便笺与陪伴感”为视觉线索，使用暖奶油纸张底色、柔和植物绿、杏橙、淡紫和青绿。
- 首页增加温暖问候卡片、功能辅助说明、编号层级与更具陪伴感的小慢助手卡片。
- 分类页统一为大标题、宽触控列表与明确返回路径，保留全部原文案和未开放提示。
- 对话页保留发送与语音准备中反馈，增强人物头像、消息层级和输入状态。
- 大字模式、浮动开关、本地记忆、键盘焦点和减少动态效果均已保留。

## 小慢形象（已确认）
- 使用用户提供的四张 3D 卡通男孩形象：挥手、微笑、倾听、活泼；以透明抠图接入，去掉原图纯色奶油背景和右下角“AI生成”水印。
- 首页人物区默认“温暖微笑”，进入首页时用“挥手问候”短暂打招呼后回到微笑；点击人物仍进入对话页。
- 对话页顶栏和机器人消息头像使用“专注倾听”，裁成头部/上半身；分类页页脚使用“活泼友好”的小尺寸陪伴形象。
- 普通模式保持两列人物卡；大字模式改为单列上下堆叠，气泡占满宽度并保持两行，人物居中放在名字和对话按钮之间。
- 保留原有入口、文案、大字模式、浮动开关和减少动态效果支持；不改旧页面或项目外页面。
