# 慢慢办 · 老年人生活助手

界面和陪伴感已经定下来了。接下来，我们把它从“看得见”做到“真的用得上”：老人打开就能接着上次继续，小慢真的能听、能答，四个板块里的每一条都能一步步学会，身体情况也能记下来、给家人看。

## 一个手机号，接着上次继续

现在的大字开关和学习进度只留在这台设备上。下一步，用一个手机号加一条短信验证码就能进来，不用记密码，也不用填一堆资料。

进来之后：

- 大字设置、学到哪一步、和小慢说过的话，都跟着您走，换一台手机也接得上；
- 每个人只看自己的内容，家人和工作人员都看不到，除非本人自己按下“分享”；
- 学习记录和对话会按日期一页页往下取，用得再久，打开也不会越来越慢。

## 小慢，真的能聊了

现在的小慢会打招呼，但回答还是提前写好的。下一步，小慢会接入 **superun General Agent** 的对话能力，成为一个能接着上下文聊下去的助手。

- 用大白话回答手机怎么用、去办事要带什么、身体不舒服先注意什么；
- 记得前面说过的话，不用每一句都从头讲；
- 遇到吃药、转账、身体不舒服这类要紧事，会明确提醒先问家人或医生，不替老人做决定；
- 每次对话只属于本人，别人看不到，也随时可以重新开始。

## 不想打字，就开口说

对话页的麦克风现在只是提示。下一步，它会真的能听：

- 按住说话，把声音转成文字（**Speech to Text**），不会打字也能和小慢聊天；
- 小慢的回答可以朗读出来（**Text to Speech**），字看不清、眼睛累了也能听；
- 没听清可以再读一遍，声音大小也能调；
- 录音只用于这一次对话，不会被公开，也不会拿来给别人听。

## 一步一步，真的学会

“学用微信”和“生活小帮手”里的条目，现在点开是“还在准备中”。下一步，每一条都会变成真正能跟着做的分步指引：

- 一次只讲一步，配上清楚的图和大字说明，点“下一步”往下走；
- 学完一条就打个勾，记住学到哪儿，下次从没学完的地方接着来；
- 常用的几条可以收藏到首页，不用每次重新找；
- 内容由我们准备好、持续更新，老人不用自己上网找。

## 防骗这件事，先停一停

防骗板块会从“提醒”变成“能商量”：

- 常见骗局用真实、好懂的例子讲，每一条配一句“记住这一句”；
- 拿不准的电话、短信、链接，可以直接问小慢，小慢会指出可疑的地方，并给出下一步建议；
- 小慢不会要验证码、不会替人转账，拿不准时会建议先打给家人或 96110；
- 小慢的判断是提醒，不是保证；真正要紧的时候，还是先和最信任的人商量。

## 身体的小账本

健康管理会变成一个每天都能用的记录本：

- 几秒钟记下血压、血糖、今天吃药没有，不用懂医学术语；
- 用简单的图和一句话看最近的变化，知道自己是稳住了还是在往上走；
- 需要时，把最近一段时间的记录整理成一页，发给家人或带给医生；
- 只有本人能看到自己的记录；分享是本人主动按下的，分享出去的内容也可以随时停掉。

## 怎么连起来

```
+-------------------------------------------+
|               老人的手机                  |
|   大字界面 · 说话 · 小慢 · 健康记录        |
+---------------------+---------------------+
                      | 登录 / 对话 / 记录 / 朗读
                      v
+-------------------------------------------+
|              慢慢办的服务                 |
|  手机号登录 · 学习内容 · 学习进度          |
|  对话记忆 · 健康记录 · 生成分享页          |
+---------------------+---------------------+
                      | 本人主动分享
                      v
+-------------------------------------------+
|         家人或医生看到的分享页            |
+-------------------------------------------+
```

- **老人的手机**——还是现在这套温暖的大字界面，新增的说话、对话和记录都长在它上面，不改变已经习惯的用法。
- **慢慢办的服务**——用 **superun Cloud Computing** 承载登录、学习内容、学习进度、对话记忆和健康记录；每个人的数据只属于本人，查看和分享都有明确的边界。
- **分享页**——只有老人自己按下分享才会生成；家人或医生看到的是整理好的一页小结，不会进入老人的完整记录。
